# 📈 AI Stock Prediction System

An Artificial Intelligence based Stock Price Prediction project using Machine Learning and Deep Learning models.

## 🚀 Project Overview

This project predicts future stock prices using historical stock market data.

It uses:
- Machine Learning (Linear Regression)
- Deep Learning (LSTM Neural Network)
- Data Analysis and Visualization

The model learns patterns from previous stock prices and predicts future trends.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow / Keras
- Streamlit
- Yahoo Finance API (yfinance)
